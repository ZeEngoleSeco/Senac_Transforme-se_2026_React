No SCSS, $ é usado para criar variáveis
@mixin funciona como se fosse uma função para chamar uma variável
name é tudo que vem antes dois :, value é tudo que vem depois
@each é um loop, que procura dentro do $ e do $value até o final, depois que acaba ele vai para o próximo
Interpolação no SCSS é feita com #, exemplo:

@each $name, $value in $pixels{
    .m-#{$name}{
        margin: $value;
    }
}
